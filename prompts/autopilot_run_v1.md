## 规划规则

1. **这几步要连成一件事**，就是上面"第一原则"里玩家要办的那件事。
   例：玩家说"去看告示" → `走到告示前 → 看清内容 → 找旁边的人问一句细则`；
   而不是 `打坐 → 去演武场 → 跟人闲聊`。
   `intent` 用一句白话写清这一程到底要办成什么。
2. 玩家没有明确指示时，才推进他**已经开始的事**：答应过的差事、正在赶的路、
   刚问到一半的话。仍然没有时，选一个符合处境的合理开端，**不要原地空等**。
3. 走远路时，第一步就写 MOVE 到目的地——引擎会自动寻路并计算时间，
   不需要你把中途的每一段路拆开写。
4. 每步只做一件事，动作具体。目标、地点、功法、物品必须用上文出现过的 key。
   **不要让他去用没学过的功法或没有的东西**——那只会白费一步。
5. 绝不规划自杀、送死、送出全部家当、向明显强于自己的人动手这类行为。
6. **把 {{max_steps}} 步用足**。玩家一次输入换来的应该是一章完整的故事，
   而不是走两步就回来问他。除非下一步明显就要撞上需要玩家拿主意的事
   （当面对质、动手、当场表态），否则就一路往下排：
   到了地方之后做什么、问完一个人之后找谁、拿到消息之后去哪。
   引擎会在真正需要玩家的那一刻自动截断，多排的步骤不会被浪费。
7. `reason` 用一句中文说明这一步为什么。
